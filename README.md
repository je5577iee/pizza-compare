# 披薩比一比

用披薩學分數比大小的小遊戲。小熊和小兔各分到一些披薩，小朋友要看披薩圖和分數，找出「誰分到的比較**多**？」或「誰分到的比較**少**？」，直接點那一盤就好。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。** 特別適合網路不穩或設備有限的環境。

## 線上使用

👉 https://je5577iee.github.io/pizza-compare/

## 離線使用

1. 在有網路的地方下載本專案的 `index.html`（點進檔案 → 右上角「Download raw file」）
2. 可複製到教室的電腦或平板
3. 點兩下用瀏覽器打開就能玩，完全不需要網路

## 玩法

選好難度後按「開始上菜！」，一回 10 題。每一盤都會畫出披薩，寫出分數，也寫出唸法（例如「八分之三」）。

每一題會隨機問「比較多」或「比較少」（大約各一半），題目裡的「多」用黃色、「少」用粉紅色標出來，提醒小朋友看清楚題目。同一回的 10 題不會重複。

### 三種難度

| 難度 | 內容 | 例子 |
|---|---|---|
| 簡單 | 切法一樣，比片數 | 3/8 和 5/8 |
| 進階 | 片數一樣，比切法（切越多片，每片越小） | 2/3 和 2/6 |
| 困難 | 切法、片數都不同，還可能**一樣多** | 2/5 和 3/4、1/2 和 2/4 |

困難模式多一個「一樣多」按鈕。用電腦玩也可以按鍵盤：← 小熊、→ 小兔、↓ 一樣多。

## 提示與鼓勵

- **答錯第一次會出現提示，可以再試一次**；第二次才答對算一半
- 提示會畫出兩條一樣長的長條並排，塗色的部分誰長，一看就知道
- 簡單：「切法一樣，片數多的就比較多」
- 進階：「切越多片，每一片就越小」
- 困難：教小朋友「先改成一樣的切法」，例如 1/2 = 2/4
- 第二次還答錯，會直接說明答案
- 答錯時不會出現傷心或責備的畫面，只有鼓勵的話

## 其他功能

- **注音開關**：首頁可以打開注音，採用國語課本的直式注音
- **音效開關**：音效由瀏覽器即時產生，不需要音檔
- 每個難度的最佳成績會以星星顯示（只存在這台裝置）
- 支援電腦、平板、手機

## 適用對象與教學建議

- **適用**：國小學生認識分數、比較分數大小，也適合課後輔導、補救教學
- **課堂示範**：投影題目，先請學生猜誰分到的比較多，再一起點
- **生活連結**：玩完後可以用紙盤或色紙剪成披薩，讓學生自己切切看、比比看
- **觀察規律**：引導學生說出「分母一樣比分子」、「分子一樣，分母越大越小」

## 注意事項

- 最佳成績只存在**那台裝置的瀏覽器**裡，換裝置或清除瀏覽器資料就會消失
- 注音經過人工檢查，若發現讀音有誤，歡迎提出 Issue 告訴我們
